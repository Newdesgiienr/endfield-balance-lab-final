Endfield Balance Lab V67 · 다중 이동·전체 보관함·우측 드래그 패널

변경 파일
- constraint-board.html
- constraint-board.css
- constraint-board.js

주요 변경
1. Shift+클릭으로 여러 제약 마크 선택
2. 선택된 제약 마크를 한 번에 같은 점수 구역으로 이동
3. 미배치 보관함의 전체 제약 보기 전환
4. 전체 보기에서 배치된 제약의 현재 점수 표시
5. 제약 카테고리명 및 페이지 전반 폰트 크기 소폭 확대
6. 오른쪽 고정 미배치 제약 패널
7. 오른쪽 패널의 제약 마크를 현황판으로 직접 드래그 배치

유지 기능
- 자동 가로·세로 그리드 정렬
- 붉은 실선 충돌 관계와 금색 이중선 시너지 관계
- 충돌선·시너지선 표시 ON/OFF
- 관계 해제, 제약 수정·완전 삭제
- 브라우저 자동 저장과 수동 버전 기록
