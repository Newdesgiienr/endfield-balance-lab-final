# Endfield Balance Lab v67

정적 HTML/CSS/JavaScript로 구성된 캐릭터 전투 구조·용어 사전·파티 분석·분석 결과·제약 추천 사이트입니다.

## 페이지

- `index.html`: 캐릭터 전투 구조 데이터베이스
- `glossary.html`: 게임 용어 사전
- `party.html`: 캐릭터 4명 편성 및 파티 메커니즘 분석
- `results.html`: 내보낸 파티 분석 목록과 상세 분석 재현
- `constraints.html`: 저장된 분석 자료를 근거로 한 제약 추천
- `constraint-board.html`: 제약 마크 제작·배치·관계 연결·버전 기록 현황판

## v55 변경 사항

- 분석 결과 목록의 각 파티 정보 바를 `분석 펼치기` / `분석 접기` 버튼으로 개별적으로 열고 닫을 수 있습니다.
- 분석 결과 페이지의 상세 출력은 파티 분석 페이지와 같은 분석 클래스와 구성 양식을 사용합니다.
- 분석 결과 페이지 안내 문구를 `파티 분석 결과를 리스트로 제공합니다.`로 변경했습니다.
- 제약 추천은 특정 파티 하나를 선택하는 방식이 아니라, 저장된 모든 파티 분석을 종합해 추천합니다. 저장된 분석이 하나라면 해당 파티만을 기준으로 합니다.
- 제약 추천 근거에는 전체 저장 파티 수와 관련 경향이 확인된 파티 수를 함께 표시합니다.
- 제약 카드의 `[제약 기능]`, `[설명]`, `[추천 근거]`, `[예상 영향]` 글자 크기를 확대했습니다.

## 분석 JSON을 사이트에 고정하는 방법

현재 `분석 내보내기`는 JSON 다운로드와 브라우저 로컬 저장을 함께 수행합니다. GitHub Pages에 분석을 고정하려면 보관한 JSON들을 `saved-analyses.js`의 배열에 합쳐 배포하면 됩니다.

## 실행

웹 서버 또는 GitHub Pages에 폴더 전체를 배포하세요. 로컬에서는 각 HTML 파일을 직접 열어도 대부분 동작하지만, 브라우저 보안 정책에 따라 웹 서버 실행을 권장합니다.

## GitHub Pages 배포용 로컬 이미지 자산

이 배포본은 `EF_CHAR.zip`의 캐릭터 초상화, 속성 아이콘, 역할군 아이콘을 사이트 내부 `assets/` 폴더에 포함합니다.
외부 이미지 서버를 호출하지 않으며, GitHub Pages와 로컬 파일 실행에서 동일한 상대 경로를 사용합니다.

- 캐릭터 초상화: `assets/characters/<character-id>/portrait.png`
- 속성 아이콘: `assets/icons/elements/`
- 역할군 아이콘: `assets/icons/roles/`
- 자산 매핑: `skport-assets.js`
- 자산 목록: `assets/asset-manifest.json`

GitHub 저장소에는 이 폴더의 **내용 전체**를 최상단에 업로드하세요. `index.html`이 저장소 루트에 있어야 합니다.

## V65 · 제약 설계 현황판 초안

`constraint-board.html` 페이지가 추가되었습니다.

- 팀·조작·환경·적 카테고리별 색상 제약 마크 제작
- 대괄호 값 강조 표시: `[2회]`, `[30%]` 등
- 1·2·3점 구역 자유 배치 및 아래로 드래그해 미배치 보관함 복귀
- 길게 눌러 붉은 실선 충돌 관계 연결
- 빠르게 세 번 눌러 금색 이중선 시너지 관계 연결
- 관계선 클릭 후 관계 해제
- 제약 마크 수정 및 완전 삭제
- 저장된 파티 분석 전체를 반영한 추천·검색·카테고리 필터
- 현재 작업 상태 브라우저 자동 저장
- 수동 버전 기록과 미리보기·불러오기·JSON 내보내기·버전 비교


## V66 · 제약 설계 작업 흐름 개편

- 제약 마크 제작 패널을 좌측의 좁은 세로형 입력 영역으로 변경했습니다.
- 우측에는 팀·조작·환경·적 네 카테고리로 분리된 가로형 미배치 보관함을 배치했습니다.
- 분석 기반 제약 추천을 제작·보관 영역 아래의 전체 너비 패널로 이동했습니다.
- 현황판 상단의 `미배치 제약 배치` 버튼으로 팝업을 열어, 스크롤 이동 없이 제약을 1·2·3점 구역에 바로 배치할 수 있습니다.
- 현황판의 제약 마크는 점수 구역마다 가로·세로 그리드에 자동 정렬됩니다. 드래그 위치에 따라 정렬 순서를 바꿀 수 있습니다.
- 충돌선과 시너지선을 각각 ON/OFF 할 수 있으며 표시 상태도 자동 저장됩니다.


## V67 · 다중 이동·전체 보관함·우측 드래그 패널

- `Shift+클릭`으로 여러 제약 마크를 선택하고, 선택된 마크 중 하나를 드래그해 같은 점수 구역으로 한 번에 이동할 수 있습니다.
- 미배치 제약 보관함의 `전체 제약 보기`를 켜면 현황판 배치 여부와 관계없이 생성된 모든 제약을 카테고리별로 확인할 수 있습니다. 배치된 제약에는 현재 점수가 표시됩니다.
- 제약 마크 상단 카테고리명과 페이지 전반의 글자 크기를 소폭 확대했습니다.
- 현황판의 `미배치 제약 열기` 버튼은 오른쪽 고정 패널을 열며, 패널의 제약 마크를 현황판으로 직접 드래그할 수 있습니다.
- 기존 점수 버튼을 이용한 빠른 배치와 자동 그리드 정렬도 유지됩니다.


## V86 · 즉시 클릭 반응 및 충돌 오버레이 개선

- 제약 마크를 클릭하면 대기 없이 총점 포함·제외와 점멸 효과가 즉시 실행됩니다.
- 빠르게 세 번 클릭하면 첫 클릭 전 총점 상태로 복구한 뒤 시너지 연결로 전환됩니다.
- 충돌 상태의 검은 오버레이를 더 투명하게 조정해 기존 제약 마크가 더 잘 보입니다.

## V87 · 충돌 선택 전환 및 비활성 영역 개선

- 충돌 상태의 흑백·반투명 효과가 카테고리 라벨 상단까지 포함됩니다.
- 충돌 상태 마크를 클릭하면 기존 충돌 상대의 총점 선택이 해제되고 마지막으로 클릭한 마크로 선택이 전환됩니다.
- 총점에 포함된 마크의 하늘색 외곽선을 더 두껍게 표시합니다.
