[V14 제약 조합 저장 패널]
- 화면 오른쪽의 ‹ 버튼으로 제약 조합 사이드 패널을 엽니다.
- 패널은 화면을 덮지 않고 본문 영역을 왼쪽으로 밀어 공간을 확보합니다.
- '제약 조합 저장' / '저장된 제약 조합' 탭을 나란히 제공합니다.
- 현재 선택한 지표의 총점, 개수, 지표명, 점수, 효과를 확인할 수 있습니다.
- 조합 이름을 입력하고 '현재 조합 저장 + JSON 추출'을 누르면 브라우저 localStorage에 저장됩니다.
- 저장과 동시에 브라우저에 저장된 사용자 조합 전체가 endfield-constraint-combinations-*.json 파일로 추출됩니다.
- '저장된 제약 조합' 탭에서 저장 조합을 불러오거나 삭제할 수 있습니다.
- saved-constraint-combinations.js는 추후 JSON 기록을 사이트 기본 저장 조합으로 편입하기 위한 파일입니다.
