Endfield Balance Lab · 실전 컨트롤 시간 프로토타입 V4

사용법
1. index.html을 브라우저에서 엽니다.
2. 상단 스테이지 구성 1~3 중 하나를 선택합니다.
3. 그 아래 파티 목록에서 한 줄을 눌러 파티를 선택합니다.
4. 웨이브별 계산은 기본적으로 모두 접혀 있으며, 필요한 웨이브의 상세 버튼을 눌러 계산 근거를 확인합니다.
5. 맨 위 계산 가정 조정에서 삼미 추가 패턴, 조류 연속공격 횟수, α 추가 패턴을 바꿀 수 있습니다.

이번 V4 UI 변경
- 스테이지 구성 + 웨이브 요약을 파티 선택 위로 이동
- 스테이지 구성 버튼과 웨이브 요약 정보 바의 가로 폭을 동일하게 정렬
- 스테이지 제목 우측에 간단한 사용 설명 추가
- 웨이브 상세 계산은 전부 접힌 상태로 시작
- 웨이브 행을 패턴 / 집결 / 중첩 / 합계의 고정 열로 정렬
- 최종 공식의 '기존 고정시간'을 '웨이브 대기시간'으로 명칭 변경

계산 원칙
- 기존 DPS 및 행동 순서는 변경하지 않습니다.
- 웨이브 대기시간은 기존 V2.0의 전체 15초 값입니다.
- 이 페이지는 별도의 추가 컨트롤 시간만 계산합니다.


V5 변경사항
- 모든 시간 표기를 초 단위로 통일했습니다.
- 최초 진입 기본 파티를 레바테인 · 아델리아 · 울프가드 · 아케쿠리로 변경했습니다.
