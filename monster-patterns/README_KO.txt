Endfield Balance Lab - 등장 몬스터 패턴 페이지 v130

실행
- index.html 또는 monster-patterns.html을 브라우저에서 엽니다.

v130 변경사항
- 기존 상세 페이지 크기/배치는 유지하고 행동 패턴 내부의 286px 격자 크기는 그대로 유지했습니다.
- 스테이지 등장 구성 영역 제거.
- 몬스터 내부 ID(eny_...) 표시 제거.
- 대응 포인트 별도 영역 제거.
- 행동 패턴 우측의 '수치 확인 / 2.1m' 형태 배지 제거.
- 격자 하단의 '확인 수치 / 개념 범위' 범례 제거.
- 격자 좌표 숫자와 우측 행동 패턴 설명 폰트를 키웠습니다.
- 행동 패턴 영역을 클릭하면 큰 모달로 확대됩니다. 배경/닫기(X)/ESC로 닫을 수 있습니다.
- 격자 1칸 축척은 패턴에 맞게 자동 조절되며, 작은 보드 외형 크기는 286px로 유지됩니다.
- 12종의 공개 Attack Range를 재확인해 사용합니다: 2.1m / 6m / 3.2m / 3.2m / 7m / 7m / 12m / 2.1m / 2.1m / 2.1m / 2.8m / 2.8m.
- Heavy Ram, Heavy Sting, Effigy 등은 최신 공개 전투 설명을 기준으로 패턴 목록을 보강했습니다.
- 개별 특수기의 히트박스/돌진 거리/AoE 반경이 공개되지 않은 항목은 임의 확정값으로 표시하지 않습니다. 해당 도형은 형태 참고용이며 실제 수치가 확인된 항목만 숫자로 표시합니다.

[v136 변경 사항]
